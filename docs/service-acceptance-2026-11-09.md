# 第二阶段验收：独立收集服务 + API + 展示端

验收日期：2026-11-09（比利时）。执行环境：Windows，Python 3.9.7。沿用 SQLite，未安装新增业务依赖。

## 交付边界

- engine/ + service/：拥有 SQLite、原文证据、增量采集、来源子进程和只读 API。
- web/ + frontend/：独立展示服务，同源转发固定 API 地址；没有 SQLite、engine 或 service 导入。
- config/service.json：配置采集间隔、启动行为、单源开关、单源超时和并发数。
- config/web.json：配置 API 目标、展示地址、默认时区和页面刷新间隔。
- 未实现数据备份、采集状态展示面板、GPT 摘要或事件自动归并。

## 运行说明与限制

验收进程完成后停止。日常运行时在两个终端分别执行 python -m service 与 python -m web，再访问 http://127.0.0.1:8766 。

默认收集服务启动立即采集；各来源完成后等待 3600 秒再运行，单源超时 300 秒，同时最多 4 个来源。配置启动时读取，修改后重启对应服务。页面默认每 60 秒刷新 API，刷新页面不会触发采集。

进程需要持续运行；未设置系统开机自启。当前 HTTP 服务定位为本机使用的最小版本。跨来源语义去重、全站历史回填、中文摘要和重大事件筛选仍属后续阶段。
